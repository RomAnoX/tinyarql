      Connection

      Staging and production colour the top edge of the window while you're connected.

      Host/Port above are then resolved from the SSH server (use 127.0.0.1 for a DB on the SSH host). Key or agent auth only — keys with a passphrase must be loaded in ssh-agent.

      The connection is encrypted, but anyone able to intercept it could pose as the server. Only for servers on networks you trust. It works for self-signed certificates, not for expired ones, and needs the openssl command.

      Unless the box above is ticked, the server's certificate is always checked, including that it names the host above. Leave the file empty for a server with a certificate from a public authority, as most cloud databases have. For a private or self-signed certificate, choose the .pem file of the CA that signed it (or the certificate itself).
